# CORE AI • Emerging Adulthood Life Transition Platform

> Interactive prototype for the academic framework integrating **Schlossberg's Transition Theory (STT 4S Model)**, **Personal Growth Initiative (PGI)**, and **Cognitive Orchestration Engine (COE)** with Apple iOS 18 design language.

---

## 📱 Features

- **Dual-Layout Responsive View**:
  - **Desktop / Laptop View**: Interactive Step-by-Step Demo Flow & Academic Citations on the left, realistic iPhone 16 Pro mockup on the right.
  - **Mobile Viewport**: Automatically hides the left demo stages and presents the native full-screen mobile app directly.
- **4S Model Implementation**:
  - **Pillar 1: Situation (Life Transition)**: Transition Mapping, Challenge Assessment (4 domains 1–10 scale), Psychoeducation Validation modal, Acceptance Framework (Dichotomy of Control -> Evolution Domain Card).
  - **Pillar 2: Self (Discovery)**: VIA Character Strengths classification (Niemiec 2020), McAdams Narrative Identity Timeline, Marcia dynamic identity status exploration & commitment profile.
  - **Pillar 3: Strategies (Navigating Growth)**: Adaptive Roadmap with mental energy capacity slider (Pilcher et al. 2022), Micro-practice daily habit checklist with Bandura (1997) self-efficacy gauge & confetti celebration, Self-Regulated Learning progress reflection.
  - **Pillar 4: Support (Collective Resilience)**: Growth Circle cohort matching (Luzanil & Menaldi 2022; Forsyth 2018) with bi-weekly process-oriented prompt, Celebrate Wins anti-comparison feed with structured peer appreciations.
- **COE AI (Cognitive Orchestration Engine)**:
  - Socratic dialog, reflective modals, and cognitive scaffolding designed to prevent cognitive offloading and foster autonomous critical thinking.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Frosted Glassmorphism + Apple SF Pro Typography
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Effects**: Canvas Confetti


### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
